## Installer da scaricare dai siti ufficiali

Questi installer superano il limite di 100 MB per file di GitHub e non sono inclusi negli zip. Scaricarli dai siti ufficiali (versione Windows x64):

| Modulo | Software | Download |
|---|---|---|
| Modulo 1 | Visual Studio Code | [code.visualstudio.com](https://code.visualstudio.com/download) |
| Modulo 1 | PowerShell 7 (`.msi`) | [Microsoft Learn](https://learn.microsoft.com/powershell/scripting/install/install-powershell-on-windows) |
| Modulo 2 | Client OneDrive (`OneDriveSetup.exe`) | [microsoft.com](https://www.microsoft.com/microsoft-365/onedrive/download) |

> [!NOTE]
> Gli script contengono solo segnaposto (`<TENANT_ID>`, `TENANT`, `XXXXXX`…) da sostituire con i valori del proprio tenant.
